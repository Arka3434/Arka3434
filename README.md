## 🔭 What I'm Working On

### 🧾 PRAMAN AI
An AI-assisted **legal metrology inspection platform**. It takes product/package images, pulls information off the labels using OCR and computer vision, turns that into structured declarations, runs configurable compliance rules on them, and generates an inspection report with evidence.

```
Image → preprocessing → OCR → structured extraction → compliance rules → evidence → report
```

AI handles the perception/extraction part, while the actual compliance reasoning stays deterministic and rule-based.

**Built with:** FastAPI · React · TypeScript · PostgreSQL · OpenCV · PaddleOCR

### 🥗 NutriTrack AI
A nutrition tracking app that tries to make food logging less annoying. Upload a photo of your meal, the backend identifies the food items, estimates the nutrition info, saves it, and updates your daily tracking.

Main things I'm working on: AI food analysis, meal tracking, nutrition calculation, a food database, backend APIs, user data and analytics.

**Built with:** React · TypeScript · FastAPI · PostgreSQL · LLM APIs

### 🍱 AI Food Scanner
An experimental project for analyzing food images with AI and getting back structured food/nutrition data. Mostly me figuring out how AI APIs, image processing and backend systems fit together.
